# Sohail Gul Korai — Portfolio

Complete editable website source, including the original portfolio photos and résumé. The live portfolio has not been changed.

## Run locally

Install Node.js 22 or newer and Bun. Open a terminal in this folder and run:

```sh
bun install
bun run dev
```

Open the local address printed in the terminal.

## Production

```sh
bun run build
```

This is a TanStack Start application, not a collection of static HTML files. Deploy using a hosting service compatible with TanStack Start and its Cloudflare build target. Do not open the source files directly as a webpage.

## Included

- All seven portfolio pages and shared navigation
- Styling and editable React/TypeScript source
- Original homepage picture, portrait, and résumé
- Package versions and project configuration

Dependencies and generated build files are deliberately excluded. This download has been checked for completeness; a separate production deployment has not been tested.
